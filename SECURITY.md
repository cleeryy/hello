# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

Only the latest minor release receives security fixes. Docker users:
run a pinned tag (`ghcr.io/cleeryy/hello:1.1.0`) or `stable`, never
an old minor.

## Reporting a Vulnerability

Open a GitHub issue with the `security` label and keep public detail
minimal until a fix ships (affected versions, impact, reproduction).
For sensitive reports, use a private security advisory instead of a
public issue.
