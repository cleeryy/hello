Run it with Docker

Quick try (token printed at the end, keep it):

export API_TOKEN=$(openssl rand -hex 16) && docker run -d --name hello -p 8080:8080 -v hello-data:/app -e DEFAULT_MAC=00:11:22:33:44:55 -e API_TOKEN=$API_TOKEN ghcr.io/cleeryy/hello:stable && echo "token: $API_TOKEN"

Persistent setup with compose:

export API_TOKEN=$(openssl rand -hex 16)
export DEFAULT_MAC=00:11:22:33:44:55
docker compose up --build

Images: stable and latest move with releases; pin 1.1.0, 1.1, 1 for reproducible deploys. Dashboard at /dashboard, API docs at /docs on your instance.

Heads-up: container bridge networks don’t forward LAN broadcast — Wake works best with network_mode: host on Linux or a plain go run on Mac/Windows.
